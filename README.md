# Shopping Cart

Created in accordance with **The Odin Project** [Project: Shopping Cart](https://www.theodinproject.com/lessons/node-path-react-new-shopping-cart)

### 🔗 [Live Preview](https://shopping-cart-gamma-lime.vercel.app/)

## Features

- Home page
- Products page
- Cart page
- Wishlist page
- Navbar live updating cart and wishlist additions

## Built With

- React + Vite
- React Router
- [FakeStore API](https://fakestoreapi.com/)
- Styled-components for styling
- [Pictogrammers](https://pictogrammers.com/) for icons
- Prettier
- Vitest for testing

## Getting Started

Setup to run locally:

1. Clone the repository.

```sh
git clone git@github.com:DarkBlueButterfly/shopping-cart.git
```

2. Navigate to cloned directory.

```sh
cd shopping-cart
```

3. Install dependencies.

```sh
npm install
```

4. Run the project!

```sh
npm start
```
